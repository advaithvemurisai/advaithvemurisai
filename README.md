**[RetailLab](https://github.com/advaithvemurisai/retail-ab-lab)** · [live app](https://retail-ab-lab-bnwnskexpoqbajnhzqgnkh.streamlit.app/)

It takes a 64,000-customer randomized experiment, prices the revenue lift at real sector margins, and returns Ship, Don't Ship, Keep Testing, or Don't Trust.
